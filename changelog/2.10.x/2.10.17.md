# 2.10.17 — 2026-09-23

## Fixed

- **`pubmed_fetch_fulltext` resolves a figure's file pointer from `<alternatives>`** when a publisher offers several renderings of it, preferring the one marked for the web. [#142](https://github.com/cyanheads/pubmed-mcp-server/issues/142)
- **Character-budget cuts end at the last word boundary**, and a subsection past the budget is dropped (or marked heading-only in `outline` mode) instead of only whole top-level sections; the `truncation` ledger reports each subsection's own accounting. [#143](https://github.com/cyanheads/pubmed-mcp-server/issues/143)
- **Unpaywall articles carry a `title`, `journalName`, and `year`** from Unpaywall's own DOI record, falling back to the Europe PMC record the chain searched, then — for HTML content only — the page's own title. [#144](https://github.com/cyanheads/pubmed-mcp-server/issues/144)
- **A titled list, definition list, or boxed text sitting outside any `<sec>`, or alone inside an untitled one, becomes a section under its own title** instead of an untitled block with no heading to separate it from its neighbors. [#148](https://github.com/cyanheads/pubmed-mcp-server/issues/148)
- **DOI input matches case-insensitively**: every casing of one DOI runs the chain once, and `unavailable[]` reports each casing as submitted. [#166](https://github.com/cyanheads/pubmed-mcp-server/issues/166)
- **`errors[]` no longer declares Unpaywall or Europe PMC failure reasons the handler never throws** — both are folded into each id's `triedTiers` instead of propagated. [#168](https://github.com/cyanheads/pubmed-mcp-server/issues/168)
- **An untitled section falls back consistently**, headed `untitled section` in both the body and the truncation ledger, and section titles are Markdown-escaped in both places. [#169](https://github.com/cyanheads/pubmed-mcp-server/issues/169)
- **A zero-padded PMC ID (`PMC0123`) resolves as the record it spells**, matching `pmcids` input with or without the `PMC` prefix in any case and fetching each record once. [#170](https://github.com/cyanheads/pubmed-mcp-server/issues/170)
