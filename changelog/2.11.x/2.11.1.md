# 2.11.1 — 2026-10-25

## Added

- **Root `plugin.json` and `mcp.json`** (Agent Plugins 1.0.0), alongside the existing `.claude-plugin/` and `.codex-plugin/` overlays.

## Changed

- **Framework `@cyanheads/mcp-ts-core` 0.13.18** — HTTP requests no longer retain about 71 KiB each through the transport's shutdown signal, which grew the heap under sustained traffic (0.13.17, [cyanheads/mcp-ts-core#786](https://github.com/cyanheads/mcp-ts-core/issues/786)); enrichment-trailer string values such as `pubmed_find_related`'s `Source` line render as code spans, so a copied value carries no backslash escapes (0.13.18, [cyanheads/mcp-ts-core#785](https://github.com/cyanheads/mcp-ts-core/issues/785)); and `content[]` text escaped by `escapeMarkdownInline` also escapes the last `#` of a trailing ` #` run and encodes leading and trailing whitespace beyond space and tab (0.13.18, [cyanheads/mcp-ts-core#781](https://github.com/cyanheads/mcp-ts-core/issues/781)). `structuredContent` is unchanged.
- **`.mcpb` bundle** — no longer ships `changelog/`, `schemas/`, `CLAUDE.md`, `.codex-plugin/`, or `devcheck.config.json` (root-anchored `.mcpbignore` lines), nor the framework's build-only files such as its `changelog/`, `templates/`, `scripts/`, and `CLAUDE.md` (0.13.18 `clean-mcpb`, [cyanheads/mcp-ts-core#791](https://github.com/cyanheads/mcp-ts-core/issues/791)).
- **README getting started** — shortened to `claude mcp add` and a generic config block; Docker and source builds moved under Running the server. The MCP SDK badge reads `^2.4.0`.
- **`.env.example`** — documents the framework's resumability, log rate-limit, tool-failure-payload, request-state-key, and OTLP base and logs endpoint variables (all commented out).
- **Bug report form** — one Environment table replaces the separate version, runtime, transport, and OS fields.
- **Docker image metadata** — OCI title is the unscoped `pubmed-mcp-server` and the description matches `manifest.json`.
- **`bunfig.toml`** — `minimumReleaseAge` holds new package versions for 1 day instead of 3.

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.13.16 → ^0.13.18
- Transitive `@opentelemetry/api` 1.9.1 → 1.10.0
